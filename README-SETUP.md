# Matrix stats dashboard — setup

Self-hosted, self-drawn GitHub stats for `agentred1999/agentred1999`.
No third-party card services — everything is generated by a scheduled
Action inside your own repo, styled to match your green-on-black theme.

## What's in this folder

```
scripts/generate_stats.py     stdlib-only generator: hero, streak, langs, year SVGs
scripts/generate_headings.py  one-off tool for lowercase-mono section headings
scripts/... (font)            assets/fonts/heading.woff2 — Fira Code, subset + embedded
.github/workflows/refresh-stats.yml
```

## 1. Copy into your repo

Drop `scripts/`, `.github/`, and `assets/` into the root of
`agentred1999/agentred1999`. Commit and push.

No extra GitHub secret is needed — the workflow uses the built-in
`secrets.GITHUB_TOKEN`, which already has read access to your public
contribution and repo data.

## 2. Run it once

Either wait for the nightly cron (`05:17 UTC`), or trigger it manually:

```bash
gh workflow run refresh-stats.yml
```

That generates `hero.svg`, `streak.svg`, `langs.svg`, and `year.svg` at
the repo root and commits them if anything changed.

## 4. Section headings (optional)

Your current README uses plain `##` headings, which is fine — this is
optional polish, not a requirement. If you want a heading in your own
typeface instead of GitHub's default:

```bash
python3 scripts/generate_headings.py "about me" assets/headings/about.svg
python3 scripts/generate_headings.py "tech stack" assets/headings/stack.svg
python3 scripts/generate_headings.py "featured projects" assets/headings/projects.svg
```

Then swap the corresponding `##` line for:

```markdown
<img src="assets/headings/about.svg" alt="about me" width="100%"/>
```

Run this locally, not in CI — headings only change when you edit the
README, not nightly. `assets/fonts/heading.woff2` (Fira Code, OFL-licensed,
subset to ~2.9 KB) is already embedded inside every heading SVG generated
this way, so it renders correctly for every visitor regardless of what's
installed on their machine — GitHub strips external font URLs.

## Notes on the numbers

- **Contribution window is pinned to whole UTC days** (`from`/`to` computed
  in the script), so re-running the workflow twice in one day never
  shifts the sparkline.
- **Language stats only count public, non-fork repos you own**
  (`privacy: PUBLIC`, `ownerAffiliations: [OWNER]`), so the percentages
  match what a visitor to your profile actually sees.
- **The workflow only commits when a file's content actually changed** —
  no nightly no-op commits cluttering your contribution graph.
- **`current` streak resets to 0 if there's a gap** of more than a day
  since your last contribution, rather than showing a stale number.
